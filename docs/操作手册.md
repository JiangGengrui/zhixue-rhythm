# 智学节律 · 运维手册（MVP）

## 1. 运行

```bash
npm install
npm start            # 构建前端 + 启动 API 与静态资源，默认 8787
```

环境变量：

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | `8787` | 监听端口，绑定 `0.0.0.0` |
| `DB_FILE` | `./data/zhixue.db` | SQLite 文件路径；测试用 `:memory:` |

开发模式：`npm run server`（API）+ `npm run dev`（Vite，`/api` 代理到 8787）。

## 2. 目录与产物

```
data/zhixue.db          运行数据（gitignore，请纳入备份）
dist/                   前端构建产物（每次 npm run build 覆盖）
server/engine.generated.mjs  由 src/domain/engine.ts 打包，改动引擎后需重新生成
```

## 3. 备份与恢复

SQLite 单文件，内置备份脚本（自动 checkpoint + 保留 14 份）：

```bash
npm run backup
```

可用系统计划任务（如 Windows 任务计划程序、Linux cron）每天定时执行 `npm run backup`。
环境变量：`DB_FILE`、`BACKUP_DIR`、`BACKUP_KEEP`。

恢复：停服 → 用备份覆盖 `data/zhixue.db`（同时删除同名 `-wal`/`-shm`）→ 启动。

## 4. 发布与回滚

1. `git pull && npm ci && npm test`
2. `npm run build`
3. 重启进程（当前为单进程 `node server/index.mjs`）
4. 冒烟：`curl -s localhost:8787/api/state` 应返回 401（未登录），页面可打开

回滚：`git checkout <上一个 tag>` → `npm ci && npm run build` → 重启。数据库结构为**只增列**（`ALTER TABLE ADD COLUMN`），旧版本代码可忽略新列，支持直接回滚。

## 5. 健康检查与排障

| 现象 | 排查 |
|---|---|
| 页面空白 | `dist/` 是否存在；`npm run build` 是否成功 |
| 接口 401 | 会话过期（30 天）或 Cookie 被清；重新登录 |
| 接口 500 | 查看进程 stderr，日志带 `[server] 未预期错误` |
| 导出文件名乱码 | 需要支持 `Content-Disposition` 的浏览器；CSV 已带 BOM |
| 容量与预期不符 | 检查「设置」页的每日可用分钟，以及是否已生成过任务块 |

常见业务码：`E1004` 参数越界、`E2001` 未登录、`E2003` 密码错误、`E1024` 时间重叠、`E1028` 跨周移动、`E1029` 恢复码无效。

## 6. 验收命令

```bash
npm test              # 引擎 20 条 + 接口 19 条
npm run typecheck     # TypeScript 严格模式
npm run build         # 生产构建
node scripts/e2e.mjs  # 真实 Chrome 全链路，截图输出到 artifacts/e2e
```

E2E 需要本机 Chrome，可用 `CHROME_PATH` 指定路径。

## 7. 安全说明

- 口令与恢复码使用 `scrypt` 加盐哈希，恢复码仅注册/重置时明文返回一次。
- 会话为 HttpOnly + SameSite=Lax Cookie，登出、改密、重置密码都会使旧会话失效。
- 登录/找回接口按 IP 限流（每分钟 10 次）；请求体上限 1MB。
- 所有查询带 `user_id` 约束；越权读写返回 404。
- 客户端离线队列以 `opId` 幂等上行，重复补传不会重复扣减工时。
- 生产部署请置于 HTTPS 反向代理之后，并定期轮换备份介质。
