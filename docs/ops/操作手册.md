# 智学节律 · 运维手册（v1.5.1）

## 1. 运行

```bash
npm install
npm start            # 构建前端 + 启动 API 与静态资源，默认 8787
```

环境变量：

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | `8787` | 监听端口，绑定 `0.0.0.0` |
| `DB_FILE` | `./data/zhixue.db` | SQLite 文件路径；测试用 `:memory:` |
| `ZHIXUE_DEMO` | 未设置 | 设为 `1` 时匿名请求回落到同一个演示账号（数据不隔离），仅用于演示 |
| `ASSISTANT_*` | 见 `server/assistant/llm.mjs` | 助手子系统模型与超时配置；未配置时降级为规则回答 |

开发模式：`npm run server`（API）+ `npm run dev`（Vite，`/api` 代理到 8787）。

## 2. 目录与产物

```
data/zhixue.db                运行数据（gitignore，请纳入备份）
dist/                         前端构建产物（每次 npm run build 覆盖）
server/engine.generated.mjs   由 src/domain/index.ts 打包（esbuild），含可行性/装箱/偏差/归因/
                              拆解/重排全部领域逻辑；改动 src/domain 后需 npm run build:engine 重新生成
docs/api/openapi.yaml         接口契约（全部端点、错误码）
```

## 3. 备份与恢复

SQLite 单文件，内置备份脚本（自动 checkpoint + 保留 14 份）：

```bash
npm run backup
```

可用系统计划任务（如 Windows 任务计划程序、Linux cron）每天定时执行 `npm run backup`。
环境变量：`DB_FILE`、`BACKUP_DIR`（默认 `backups/`）、`BACKUP_KEEP`（默认 14）。

恢复：停服 → 用备份覆盖 `data/zhixue.db`（同时删除同名 `-wal`/`-shm`）→ 启动。

## 4. 发布与回滚

### 4.1 本地 / 单机

1. `git pull && npm ci && npm test`
2. `npm run build`
3. 重启进程（单进程 `node server/index.mjs`）
4. 冒烟：`curl -s localhost:8787/api/state` 应返回 401（未登录）；`/` 能打开

回滚：`git checkout <上一个 tag>` → `npm ci && npm run build` → 重启。数据库结构为**只增列**（`ALTER TABLE ADD COLUMN`），旧版本代码可忽略新列，支持直接回滚。

### 4.2 线上：CloudStudio 沙箱（当前）

沙箱访问不了 npm 公共源，**不能**在沙箱里 `npm install`，只能上传预构建产物：

1. 本地 `npm test && npm run build` 全绿；
2. 暂存运行所需的最小集合 —— `dist/`、`server/`、`package.json` 三部分（约 3.4 MB，192 文件）；
3. 上传该目录，启动命令 `node server/index.mjs`，端口 `8787`；
4. 冒烟见 4.4。

沙箱是临时环境，可能被回收；需要长期地址时走 4.3 或绑定自定义域名。

### 4.3 线上：CloudBase 云托管（备选）

仓库内 `Dockerfile`（多阶段构建）+ `cloudbaserc.json` 已就绪：

1. 在同目录 `.env.local` 填 `ENV_ID`（`cloudbaserc.json` 的 `envId` 是 `{{env.ENV_ID}}`）；
2. `tcb cloudrun deploy`（或控制台按仓库 Dockerfile 构建）；
3. 容器内 `PORT=80`、`DB_FILE=/app/data/zhixue.db`、`MinNum=1 / MaxNum=1`，前后端同域，无需 CORS。

注意：容器内 SQLite 是**实例本地存储**，重新部署会重置为全新空库；需要留数据时把 `DB_FILE` 指向挂载卷，或迁到云数据库。

### 4.4 线上冒烟

| 检查 | 期望 |
|---|---|
| `GET /` | 200，引用 `/assets/app-*.js` |
| `GET /api/state` | 401 `E2001`（鉴权生效） |
| `GET /api/visit` | 200，`{"count":N}` |
| `POST /api/auth/guest` | 200，下发游客会话 |
| `GET /assets/matter-*.js` | 200（改动效后必查，确认分包已上传） |

## 5. 健康检查与排障

| 现象 | 排查 |
|---|---|
| 页面空白 | `dist/` 是否存在；`npm run build` 是否成功 |
| 接口 401 | 会话过期（30 天）或 Cookie 被清；重新登录 |
| 接口 500 | 查看进程 stderr，日志带 `[server] 未预期错误` |
| 导出文件名乱码 | 需要支持 `Content-Disposition` 的浏览器；CSV 已带 BOM |
| 容量与预期不符 | 检查「设置」页的每日可用分钟，以及是否已生成过任务块 |
| 动效不生效 | 系统开启「减少动效」时会整体降级；`matter-*.js` 未上传则七天堆积不渲染 |
| 助手答非所问 | 未配 `ASSISTANT_*` 时走规则回答，见 `docs/assistant/` |

常见业务码：`E1004` 参数越界、`E2001` 未登录、`E2003` 密码错误、`E1024` 时间重叠、`E1028` 跨周移动、
`E1029` 恢复码无效、`E4009` 拆解覆盖未确认、`E1033` 未知重排方案、`E1034` 重排后仍装不下、
`E1035` 达到同周重排上限、`E1036` 重排方案不适用。完整契约见 `docs/api/openapi.yaml`。

## 7. 安全说明

- 口令与恢复码使用 `scrypt` 加盐哈希，恢复码仅注册/重置时明文返回一次。
- 会话为 HttpOnly + SameSite=Lax Cookie，登出、改密、重置密码都会使旧会话失效。
- 登录/找回接口按 IP 限流（每分钟 10 次）；请求体上限 1MB。
- 所有查询带 `user_id` 约束；越权读写返回 404。
- 客户端离线队列以 `opId` 幂等上行，重复补传不会重复扣减工时。
- 生产部署请置于 HTTPS 反向代理之后，并定期轮换备份介质。
